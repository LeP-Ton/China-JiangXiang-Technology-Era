# 包装差异与跨模块展示

## 背景与目标

- 会话-35，用户询问包装选择后为何在其他页面看不到，并指出简装和雅致过于相似。
- 原方案只在实验室预览与灌装后产品卡展示，未灌装档案只有文字；简装复用白瓷瓶和金盖，仅调整了细节颜色。
- 让包装从设计阶段持续可见，并通过瓶型、材质、封盖及标签区分包装档位。

## 约束与决策

- 沿用 React / SVG，动态品牌文字和企业徽记仍实时同步，不引入图片服务或新依赖。
- 简装采用透明长颈玻璃瓶、可见酒液、银色短旋盖、红色防拆环及素纸标；雅致保留白瓷、金色封盖及压纹；典藏保留深翠描金。
- 设计效果、生产目标和已灌装成品明确区分，不因显示酒瓶增加产品库存。
- 修改配方包装不会重标已有成品；同配方不同包装分别灌装入库，同包装继续按原规则合并。
- 不更改 v1 存档结构，保留旧产品 ID，产品集合上限从 20 调整为 60，容纳 20 配方的三档包装。

## 主要文件

- `src/components/WineBottle.tsx`：独立简装瓶体、透明酒液和素纸标签，共用徽记及品牌排字。
- `src/components/ProductAppearance.tsx`：共用包装缩略图、品牌、产品名与经营阶段说明。
- `src/App.tsx`、`src/components/shared.tsx`：跨页携带产品 / 配方选择，产品卡发货时不误选其他包装。
- `src/components/Laboratory.tsx`：包装预览、材质说明及材料成本。
- `src/components/Commerce.tsx`：持续保留设计档案、真实成品和发货包装、口碑表缩略图。
- `src/components/Operations.tsx`：当前生产方案、在制计划和勾调目标包装。
- `src/brand-visuals.css`：不同材质背景、缩略图及紧凑列表布局。
- `src/game/data.ts`、`flavor.ts`、`actions.ts`：统一包装成本与描述，按实际包装合并成品。
- `src/game/storage.ts`：兼容三档包装独立库存的集合上限。
- `tests/simulation.test.ts`：包装改版不影响旧成品、新包装独立发货、同包装合并及读档回归。

## 风险与验证

- 多瓶共存必须保持 SVG 渐变和裁剪 ID 唯一，避免材质串色。
- 发货按成品快照展示，生产和勾调按所选配方展示；已在制任务仍保留启动时方案。
- 简装透明材质、小尺寸排字和手机布局需要浏览器视觉验证。
- 原有经营规则、旧档、长期月结以既有回归套件验证，新增包装库存用例验证费用、库存、渠道及读档。

## 验证结果

### TC-001 包装切换与归档

- 在风味雷达模式切换简装，自动显示透明玻璃瓶预览，材料费为 5 元，雅致为 16 元，典藏为 48 元。
- 保存简装配方后，产品设计档案立即显示简装图；刷新并重新打开实验室仍显示简装。
- 结果：通过。

### TC-002 设计、在制和成品的区别

- 当前生产方案显示最新简装；已有在制任务仍显示启动时的雅致目标。
- 勾调页显示所选配方包装，实际灌装前不增加产品库存。
- 结果：通过。

### TC-003 多包装库存与发货

- 旧雅致成品 618 瓶保持不变，另行灌装简装 2,000 瓶，发货简装 500 瓶后仅简装库存减少至 1,500 瓶。
- 随后灌装典藏 1,000 瓶，三档包装可同时存在；发货下拉框与口碑表分别显示对应图样。
- 从简装产品卡点击安排渠道发货后，直接选中简装库存。
- 结果：通过；引擎回归还验证同包装合并、包装费用、渠道引用和存档往返。

### TC-004 布局与回归

- 390px 页面宽度与文档宽度均为 390，包装图及设计档案无横向溢出；抽屉关闭后瓶身完整可见。
- 浏览器控制台无警告或错误，临时视口已恢复。
- 26 项引擎回归通过，包含 72 月经营；TypeScript 与 Vite 生产构建通过。
- 本地对比截图保存在 `artifacts/简装与雅致对比.jpg`，不提交入库。
