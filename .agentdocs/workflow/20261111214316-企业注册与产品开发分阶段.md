# 企业注册与产品开发分阶段

## 背景与目标

- 会话-28，用户指出创建企业不应强制填写白酒品牌和核心产品，它们应属于后续经营活动。
- 原实现为快速打通 MVP，预置了命名品牌、配方、3,200 瓶成品及 1,600 瓶渠道库存，混淆了企业成立与产品上市。
- 新流程：创立酒厂 → 设计品牌与首款配方 → 组织生产 / 使用既有基酒勾调 → 形成成品 → 销售。

## 约束与决策

- 新企业创建只需要名称、企业标识、发展方向和经营种子。
- 新企业保留原料、设备、人员、14 吨开局基酒与待供货渠道，不预设品牌、配方、成品或终端销售。
- 品牌和产品由玩家进入配方实验室后命名，并与风味、定位、包装一起设计。
- 保存方案不增加成品；实际勾调消耗基酒与费用后才创建产品库存。
- 原 v1 存档保留品牌、产品和库存，不清零、不强制重新创建。

## 主要变更

- `src/game/types.ts`：新增 `CompanySetup`，企业成立输入不含品牌与产品。
- `src/game/state.ts`：新游戏品牌、配方、成品和渠道货物为空；开局基酒使用独立工艺来源 `initial-process`。
- `src/game/actions.ts`：首款配方归档后补充企业首品牌 / 产品元数据；不直接生成成品。
- `src/game/storage.ts`：允许零配方、零产品的有效存档，维持旧档格式。
- `src/game/market.ts`、`events.ts`：尚未上市不承受虚构产品评价，不触发缺少对应经营事实的质量与宣传事件。
- `src/components/Setup.tsx`、`WineBottle.tsx`：注册信息与未命名形象酒瓶。
- `src/components/Laboratory.tsx`：空白首款方案、品牌命名、包装预览与风味雷达切换。
- `src/components/Commerce.tsx`、`Operations.tsx`、`Dashboard.tsx`、`shared.tsx`：空状态引导、产品方案与成品分开显示。
- `src/components/Charts.tsx`：没有历史结算时不再绘制预置 1,600 瓶渠道库存。
- `src/App.tsx`、`src/brand-visuals.css`：开户通知、经营手册与分阶段样式。
- `tests/fixtures/operating-company.ts`：用独立存量档案场景保留既有经营回归。
- `tests/simulation.test.ts`：新开局、后置设计、旧档及长期经营测试。

## 关键实现与风险

- 所有页面不能再假定 `recipes[0]` 或 `products[0]` 存在。没有方案时提供真实设计入口，而不是生成默认商品。
- 开局基酒独立于玩家产品方案，调整新配方不会改变已交接基酒的历史工艺与风味。
- 仍保留 `company.brand` / `company.product` 字段兼容旧档，新企业初始为空，首款配方归档后赋值。
- 无产品时显示“待上市”，筹备期营收和动销为零，工资、仓储等成本照常结算。
- 企业创建与产品开发分阶段已作为长期业务约束写入 AGENTS.md。

## 测试用例

### TC-001 只创建企业

- 类型：浏览器 + 引擎回归；优先级：高。
- 操作：仅填写“初原酒业”，选择标识与发展方向后开始经营。
- 预期：注册表单没有品牌和核心产品输入，游戏正常进入驾驶舱，成品与渠道库存为零。
- 状态：通过。

### TC-002 空状态与筹备期

- 类型：浏览器 + 引擎回归；优先级：高。
- 操作：刷新空白企业，访问生产、储存、产品、经销、营销和财务，并推进月结。
- 预期：不崩溃、不提示损坏存档；首月收入、回款与动销均为零，固定费用正常发生。
- 状态：通过。引擎还连续验证 8 个筹备月份，未凭空产生销售或产品事故。

### TC-003 成立后设计和投产

- 类型：浏览器 + 引擎回归；优先级：高。
- 操作：在实验室命名“初原 / 谷序·首酿”，保存方案，安排 3 吨生产，再使用成熟基酒勾调 2,000 瓶。
- 预期：设计时实时预览，保存后只有方案；实际勾调后才出现可售产品。
- 状态：通过。归档后产品卡数量为 0，勾调后为 1。

### TC-004 首笔销售

- 类型：浏览器功能测试；优先级：高。
- 操作：首批成品向经销商发货，再结算。
- 预期：出货、终端动销、渠道库存与收入真实联动。
- 状态：通过。筹备首月收入为零，产品上市后首笔月结收入 17.56 万。

### TC-005 旧档与长期经营

- 类型：回归测试；优先级：高。
- 操作：读取旧品牌档案；从零品牌新企业开始，设计产品并连续经营 72 月。
- 预期：旧档原有 3,200 瓶企业库存和 1,600 瓶渠道库存保留；新企业可持续经营并保存。
- 状态：25 项回归全部通过，TypeScript 与 Vite 构建通过。
