# 中国酱香科技时代

一款运行在浏览器里的中国白酒企业经营模拟游戏。管理一家原创虚构的酱酒企业，在技术、品质、库存、现金流、品牌和渠道之间做出有代价的选择。

## 开始游戏

正式地址：[中国酱香科技时代](https://lep-ton.github.io/China-JiangXiang-Technology-Era/)。

创建企业时只确定企业名称、标识和发展方向。新酒厂拥有原料、基酒、设备与人员，没有预设品牌、配方和成品。品牌和产品是在企业成立后做出的经营决策。

每个月有 **5 次管理行动**。推荐第一月：

1. 进入配方实验室，创立品牌、命名首款产品并归档工艺。
2. 完成一次盲品，或投入“风味指纹分析”研究。
3. 下达 3 吨基酒生产计划。
4. 从已接收的 12 月基酒中勾调灌装 2,000 瓶，形成首批成品。
5. 向一家经销商发货，再推进下个月。

成品库存自动参与月末电商直销。研发分四阶段，完成后需部署；生产耗时数月，新酒入库后从 0 月酒龄陈酿。开局提供成熟基酒供早期周转。

## 经营规则

- **风味有取舍**：焦香挤压果香，精细摘酒增加原料，长发酵占用车间，陈酿增益递减。
- **账面与真实分开**：发货确认收入，赊销只收 40% 现金，终端动销决定渠道能否持续打款。
- **压货有后果**：积压导致倒挂、健康下降、拒收和逾期坏账。
- **技术影响生产**：出酒率、原料耗用、发酵周期、灌装与风味稳定性实际联动。
- **概念有账单**：夸大宣传短期提升热度，后续可能调查、退单、损失和信誉下降。
- **时间可以继续**：60 月后六维评价，支持自由经营；现金连续三月为负则清算。

企业、人物、品牌和故事均为原创虚构。1 吨基酒折算约 2,000 瓶，工艺、税费和产业周期是玩法抽象。

## 存档

每次有效操作自动保存；档案室提供三个手动槽位与 JSON 文件导入导出。相同种子和操作顺序可复现关键经营结果。

存档保存在当前浏览器与站点，不自动跨设备同步。清理浏览器数据可能删除进度，重要决策前建议手动保存并导出备份。本地存档可以导出后导入正式站点。

## 本地开发

使用 Node.js 24 和 npm：

```powershell
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/`。

```powershell
npm test
npm run build
npm run preview
```

`npm run format` 整理源码。核心为 TypeScript 纯函数模块，界面为 React，Vite 构建，Recharts 绘图。

## GitHub Pages

`main` 推送触发 `.github/workflows/deploy.yml`：锁定依赖安装 → 回归测试 → Pages 子路径构建 → 上传 `dist` → 发布。

本地模拟正式子路径构建：

```powershell
$env:VITE_BASE_PATH = '/China-JiangXiang-Technology-Era/'
npm run build
```
